下載與第一次使用

只需要一台 Mac、一條 USB 線和你的 iPhone。

第一次打開 App

  1. 下載 .dmg，把 App 拖進「應用程式」資料夾。
  2. 如果 macOS 顯示「無法打開」，到 系統設定 → 隱私權與安全性，往下找到這個 App，按 強制打開。
  3. 之後就能像一般 App 一樣直接打開。

連接 iPhone

  1. 用 USB 線 連接（Wi-Fi 不行），並解鎖手機。
  2. 第一次連接時，iPhone 會問「要信任這部電腦嗎？」，請按 信任 並輸入密碼。
  3. 在 App 裡按 讀取 iPhone 就可以開始了。

常見問題

會不會把我的主畫面弄亂？

每次讀取都會自動備份原本的排版。套用後如果不滿意，按左邊的「還原原本排版」就會回到原樣。套用前也會先讓你預覽。

有 Windows 版嗎？

目前只支援 macOS。

可以用 Wi-Fi 連接嗎？

不行，需要用 USB 線連接，並且手機要解鎖。

支援 iPad 嗎？

目前只針對 iPhone 設計和測試。

為什麼不能直接在網頁或 iPhone 上用？

iOS 不允許網頁或手機上的 App 讀取或修改主畫面排版，只能透過電腦以 USB 連線處理。

iOS 更新後不能用了怎麼辦？

這個工具用的是 Apple 沒有公開的連線方式，iOS 改版時有可能失效。遇到問題請到 GitHub 回報，我會盡快更新。
